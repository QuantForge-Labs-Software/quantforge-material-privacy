Material Calculator · Windows desktop · Store ID 9PNRCK43GW8F

Getting an estimate

Select a material, enter your metric measurements and use a decimal point for fractional values. Enter waste and the supplier’s unit price. Masonry and tiles round up to whole pieces after waste.

Saving a report

Choose Export estimate and select a writable folder. If an existing report is open in another application, close it or save under a new name.

Open a public support request

For a product question, include the app version, calculator type, steps and expected result using made-up measurements. GitHub issues are public. Keep names, contact details, client estimates, invoices and account information private.
